## Technical Implementation

| Claim | Evidence | How to check |
|---|---|---|
| Real local RAG, not a wrapper | `backend/{ingest,embed,retrieve,answer}.py` | `python tests\test_pipeline.py` |
| Retrieval is grounded, not decorative | Relevance gate refuses **before** the LLM is called | Ask an out-of-corpus question; no model call happens |
| Citations are verified, not printed | `answer.validate_citations()` drops markers not matching a supplied chunk | `python -m backend.answer` |
| Local ASR | `backend/asr.py` | `python tests\test_asr.py` |
| Local LLM over an OpenAI-compatible endpoint | `backend/llm.py` | `scripts\start_llm.ps1` |
| Offline operation is proven | Non-loopback sockets blocked, pipeline still passes | `python tests\test_egress.py` |
| Snapdragon path is in code, not prose | `config.ort_providers()`, reported at `/api/health` | `scripts/setup_snapdragon.md` |
| Benchmarks are real | `benchmarks/RESULTS.md`, generated by `benchmarks/run.py` | Re-run it |

**The strongest technical point is the negative one:** the system is built so that it *cannot*
cite a page it was not shown. That is enforced in code and tested, not requested in a prompt.

## Use Case & Innovation

| Claim | Where |
|---|---|
| Not a "chat with PDF" tool — the loop ends in a quiz | `backend/quiz.py`, FR-11…FR-14 |
| Weak-topic detection closes the loop back into explanation | Quiz → named topic → grounded answer, one click |
| Questions carry their source chunk from generation | Makes explanations grounded by construction (ADR-05) |
| Hinglish **output**, not Hinglish input | The feasible side of the multilingual problem (ADR-09) |
| Refusal is a feature shown in the demo | `DEMO.md` step 5 |

The insight worth stating out loud: students' material is in English but their *understanding*
happens in Hinglish. Most tools solve translation in the wrong direction, or not at all.

## What we explicitly do NOT claim

Stated here because omitting it would be the dishonest version of this document.

1. **No NPU execution has been measured.** The dev machine has no NPU. Per ONNX Runtime's
   documentation, `win-x64` supports QNN quantization and AOT compilation only — not inference.
   Every NPU statement in this repository is a documented deployment path with a citation.
2. **The Snapdragon benchmark column is empty** and labelled *requires hardware*.
3. **The shipped ASR backend has no NPU path.** faster-whisper is CTranslate2 on CPU. The
   Qualcomm AI Hub Whisper path is documented and unimplemented. `/api/health` names the
   active backend at runtime.
4. **ASR accuracy is not characterised.** It was tested with synthesized speech, which is far
   cleaner than real student audio. That proves the pipeline is wired, not that WER is good.
5. **The LLM licence is not OSI-approved.** Llama Community Licence, accepted deliberately over
   an Apache alternative for measured Indic quality (ADR-10), with attribution in `LICENSE`.

> Any of these could have been quietly omitted or rounded up into a stronger-sounding claim.
> They are stated because a submission whose honesty is verifiable is worth more than one whose
> numbers are not — and because the brief explicitly forbids fabricated results.
